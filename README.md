## 📌 O projekte

Microhabits Champions je moderná a interaktívna webová aplikácia navrhnutá na budovanie mikronávykov (microhabits), gamifikáciu osobného rozvoja a každodennú motiváciu. 
Projekt kombinuje čistý minimalistický dizajn s pokročilými webovými technológiami a interaktívnymi prvkami priamo vo vašom prehliadači.

Kľúčové vlastnosti

Sledovanie mikronávykov: 
Jednoduché pridávanie, odškrtávanie a sledovanie denných cieľov a návykov.

Gamifikačný systém & Streaks: 
Motivujúce počítadlo úspešných dní v rade (streaks), levely a odmeny za konzistenciu.

Responzívny dizajn: 
Optimalizované rozhranie pre počítače aj mobilné zariadenia.

PWA (Progressive Web App): 
Možnosť okamžitej inštalácie do zariadenia s podporou offline režimu.

Rýchly a čistý kód: Postavené na moderných základoch HTML5, CSS3 a vanilkovom JavaScripte bez zbytočných ťažkých frameworkov.


Použité technológie

Frontend: 
HTML5, CSS3 (Custom Properties, Flexbox / Grid), JavaScript (ES6+)

Úložisko dát: 
Lokálna vyrovnávacia pamäť (localStorage pre okamžité ukladanie pokroku bez nutnosti registrácie)

Hosting: 
GitHub Pages
